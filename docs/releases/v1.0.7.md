# Switch v1.0.7

UI overhaul release: full high-DPI support, window chrome fixes, a denser sidebar, a smarter logs view, and a batch of interaction fixes.

## Highlights

- **High-DPI support everywhere.** All owner-drawn layout metrics and fonts now scale by the monitor DPI and rebuild live when the window moves between monitors. On 125%/150% displays, text previously grew out of fixed-size boxes and overlapped; the whole shell now renders in correct proportion at any scale factor.
- **Window chrome fixes.** Maximizing the borderless window no longer covers the taskbar (WM_GETMINMAXINFO), resize edges are disabled while maximized, and a MINMAXINFO field-order slip that collapsed the maximized window to 0x0 is fixed.
- **Denser sidebar.** The brand title and summary line are gone; the workspace mode switch and stop-all share one compact 46px row, item counts moved into the section headers, and cards/gaps/buttons are 25-50% smaller -- roughly twice as many commands and sites fit on screen.
- **Sidebar usability.** Drawn scrollbars with drag and track paging, smooth precision-touchpad scrolling, ID-keyed hit testing (no more clicking the wrong entry after list changes), an explicit keyboard focus model (Tab/arrows/Enter/Delete with a focus ring), full command text in tooltips, button-styled empty states, and text health badges that stay readable for color-blind users.
- **Smarter logs view.** stderr lines are colored red, with a filter box, word-wrap toggle, copy-selection-or-all, and a clear confirmation; the toolbar no longer overlaps on narrow widths.
- **Interaction fixes.** Layout (window placement, sidebar, workspace mode, split ratio, selection) persists across restarts; popups open in the system browser instead of hijacking the current page; right-click selects without forcing navigation; config import resets dangling selections and disposes stale WebViews; dialogs validate inline, cap to the work area with scrolling, and no longer drop invalid environment-variable lines silently.
- **New shortcuts.** Ctrl+1/2/3 workspace modes, Ctrl+B sidebar, F5 reload, Alt+Left/Right history, Ctrl+L address bar. A title bar overflow menu exposes settings, import/export, logs, and Exit inside the window.
