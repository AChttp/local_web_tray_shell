# Switch v1.0.8

Polish release that trims the custom title bar to standard height.

## Highlights

- The custom title bar is now 32px tall (was 44px at 96 DPI), matching standard Windows title bars and freeing a bit of vertical space for the workspace. The sidebar toggle and overflow menu buttons are smaller and vertically centered; minimize/maximize/close keep their standard-width hit areas. Dragging and double-click-to-maximize behave as before.

## Included In This Release

- `Switch.exe`
- `Switch-v1.0.8-win-x64.zip`

## Runtime Requirement

- Microsoft WebView2 Runtime must be installed on the target Windows machine
